# Public Product Language

Use public product names in anything users can see.

- Prefer **Tangle** or **Tangle UI**.
- Use **Tangent** or **Tangent Shell** only when that product is specifically relevant.
- Do not expose internal repository, service, project, deployment, or infrastructure names.
- Replace an internal backend name with **Tangle backend**, **backend**, or **managed AI service**, whichever is clearest.
- Keep internal names only where code must match an API route, identifier, configuration key, import, or other implementation detail.
- Before finishing a user-facing text change, review the changed copy for internal names.
